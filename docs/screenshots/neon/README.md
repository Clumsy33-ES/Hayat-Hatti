# Neon PostgreSQL – Production Veritabanı Kanıtları

Bu klasör, Hayat Hattı projesinde kullanılan
**Neon PostgreSQL (production)** veritabanına ait
canlı ortam kayıtlarını göstermektedir.

Frontend üzerinden yapılan kullanıcı kayıtları ve SOS/sinyal gönderimleri,
backend aracılığıyla doğrudan Neon veritabanına kaydedilmektedir.

Aşağıdaki ekran görüntülerinde:
- users tablosuna düşen kullanıcı kayıtları
- signals tablosuna düşen SOS/sinyal verileri
görülmektedir.
